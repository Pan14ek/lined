# Lined Shared Engineering Handbook

This is the monorepo-owned source for guidance that applies across backend and
web work. It keeps cross-project vocabulary at the Lined root while each
sub-project owns its implementation-specific patterns.

## Navigation

- [GoF patterns](design-patterns/gof/README.md) — 23 patterns with applicability and anti-overengineering guidance.
- [Lined Pattern Registry](registry/LINED_PATTERN_REGISTRY.md) — audited owners and consumers across backend and web.
- [Backend engineering handbook](../../backend/lined/docs/engineering/README.md) — Spring/Lined guidance and backend patterns.
- [Web engineering handbook](../../lined-web/docs/engineering/README.md) — React/TypeScript guidance and web patterns.

## Ownership rule

Keep general engineering vocabulary and cross-surface ownership records here.
Keep Spring-specific patterns in `backend/lined/docs/engineering/` and
React/TypeScript-specific patterns in `lined-web/docs/engineering/`.

## Maintenance

Update this index and the owning sub-project index when shared guidance is
added, moved, or renamed. Keep the documents self-contained; external websites
are not required.
