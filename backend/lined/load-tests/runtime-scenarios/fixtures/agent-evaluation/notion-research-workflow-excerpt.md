# Research Workflow for Agents

- Update Notion first for durable knowledge.
- Every agent-produced rule, summary, or recommendation should include acceptance criteria, evidence source, uncertainty, and review status.
- Agents should state which Notion pages, repo docs, and experiment artifacts were loaded, and which relevant sources were skipped.
- Accepted and rejected LLM suggestions should be stored with reason codes so future prompts, retrieval rules, and evaluation rubrics can improve.
